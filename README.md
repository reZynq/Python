**HELLO**

This is a python script which simulates a weather app using an API Key from a website

**ADD API KEY**

Website for api key 
https://openweathermap.org/ 

1) Create an account
2) Click on your account and click on API keys
3) Copy and paste into code

**INSTALL PACKAGES**

1) Go to terminal
2) pip install PyQt5

After that, everything should be ready to run!
